## CRITICAL HANDOFF MOMENTS

**Landing → Samuel's Page:**
- User feels: "I need more proof"
- Experience must feel: Cinematic, not informational
- Danger: Page feels generic, copy-pasted, not premium

**Samuel's → Request Deliverance:**
- User feels: "OK, I'm ready"
- Experience must feel: Simple, safe, no commitment yet
- Danger: Form feels cold, transactional

**Request → WhatsApp Contact:**
- User feels: "Is anyone actually there?"
- Experience must feel: Personal, immediate, real
- Danger: Silence = abandonment

**Prayer → Decision to Restore:**
- User feels: "I was actually delivered"
- Experience must feel: Transformative, not programmatic
- Danger: Feels like joining a club instead of encountering Jesus

## DESIGN CONTINUITY ACROSS ALL PAGES

Every page must:
- ✅ Use the same color palette
- ✅ Use serif for spiritual language
- ✅ Use same spacing rhythm (py-24 md:py-32)
- ✅ Use scroll-triggered animations
- ✅ Use 2xl max-width for content
- ✅ Use prophetic, spare language
- ✅ Have clear CTAs (action-specific)

**NOT negotiable:** A visitor should feel they're on the same site, experiencing the same ministry, regardless of which page they land on.
