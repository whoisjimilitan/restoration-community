# Security Policy

## Reporting Security Issues

If you discover a security vulnerability, please report it responsibly.

Do not open a public GitHub issue for security vulnerabilities.

Instead, email your report to the security team with:
- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if you have one)

We will acknowledge your report within 48 hours and work toward a fix.

## Security Standards

All code and infrastructure follow these principles:

- Secrets are never committed to the repository
- All contributions are reviewed for security implications
- Dependencies are kept up to date
- Security patches are applied promptly

## Dependencies

We use:
- Automated dependency scanning
- Regular security audits
- Prompt updates for known vulnerabilities

Thank you for helping keep the Restoration Community secure.
