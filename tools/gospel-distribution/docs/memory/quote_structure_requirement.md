# BOBA QUOTE STRUCTURE REQUIREMENT (NON-NEGOTIABLE)

**This is a GATE. No processing proceeds without this structure.**

---

## THE RULE

Boba always sends quotes in **numbered positions**, not individual statements.

Each numbered position contains **multiple related statements** that together form **ONE complete teaching**.

Example structure:
```
One.
[Statement 1]
[Statement 2]  
[Statement 3]

---

Two.
[Statement 1]
[Statement 2]
[Statement 3]

---

Three.
[Statement 1]
[Statement 2]
etc.
```

---

## WHAT THIS MEANS

✓ **Each numbered section (One, Two, Three... Nine) = ONE complete teaching**

✓ **Never process individual statements** — Statements only have meaning grouped within their position

✓ **Never split a position** — All statements under a position are processed together

✓ **Never confuse partial content** — A single statement is NOT a quote; it's part of a quote

---

## VERIFICATION CHECKLIST

Before processing ANY content:

- [ ] Is this content numbered (One, Two, Three)?
- [ ] Does each number contain multiple related statements?
- [ ] Are statements separated by "---" between numbered sections?
- [ ] Is this a COMPLETE position (all statements present)?

If ANY of these is "No":
→ STOP
→ Do NOT process
→ Flag for user review
→ Ask for confirmation of structure

---

## WHY THIS MATTERS

1. **Single statements are incomplete** — They lose context when isolated
2. **Positions form complete teachings** — All statements together create the full revelation
3. **Processing error cascades** — Treating a statement as a quote invalidates all downstream work
4. **Quality depends on completeness** — /preach and /teach both require the full position to work properly
