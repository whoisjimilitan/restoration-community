## KEY RULES

✓ Side-by-side format (not sequential)
✓ Scripture: Full verse included (Chapter:Verse — "[Full text]") — no lookup needed
✓ Scripture shown once (under full /preach in VERSION A)
✓ VERSION A shows the full /preach piece (for context)
✓ VERSION A shows the extracted 40-second HIDE reel
✓ VERSION B shows only the 40-second HIDE reel built from scratch
✓ Both are ready to record
