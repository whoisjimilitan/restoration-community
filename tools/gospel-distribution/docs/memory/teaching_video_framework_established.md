## Framework Definition (Canonical)

Every teaching video follows a three-part arc:

1. **QUESTION (Setup)** — Hook (camera touch) + establish presence (sit down) + probing question that creates intellectual/spiritual tension
2. **ANSWER (Body)** — Resolve the question through Scripture and teaching; structure: Define → Confront → Escalate → Resolve → Illustrate → Call
3. **BLESSING (Close)** — A benediction (not a teaser, not thanks); send viewers out transformed with a wish/charge for their lives

**Why:** This framework lets the message speak for itself. Design serves clarity only, never competes with the teaching.

## How to Apply This Framework to Future Videos

1. **Listen to raw recording** — identify what question the teaching answers
2. **Make surgical cuts** — remove false starts, retakes, tangents that don't answer the core question
3. **Cut for pace** — remove repetition, over-elaboration, and drag. If a point is clear in one sentence, don't repeat it. If removing a section doesn't break the teaching, cut it (it was drag).
4. **YouTube discipline** — Get to the question in first 60s. Build momentum in the body (no circles, no wandering). Body escalates continuously toward the call.
5. **Verify the probing question** — is it clear, challenging, real?
6. **Verify the closing blessing** — does it send them out transformed, or redirect them?
7. **Compose without design flourish** — the framework itself is the design

**Do NOT:** Add section labels, end screens, or teasers (fragments the message); allow drag or repetition (kills YouTube engagement). **DO:** Trust the teaching to carry weight; cut for pace and impact.

## Narrative Stage Architecture

**Universal spine (all messages):**
1. Opening (gap/question)
2. Revelation (core truth)
3. Proof (Scripture/illustration)
4. Call (action)

**Optional middle layers (add only if they serve the revelation):**
- Diagnosis (correct misunderstanding)
- Indictment (name the gap)
- Escalation (show consequences)
- Power (introduce ability)
- Resolution (problem → solution)

**REC049 uses all 7 because it's action-vs-theory.** A grace teaching uses 4. A suffering teaching uses 5. **Build the spine around what must be revealed, not around a formula.**
