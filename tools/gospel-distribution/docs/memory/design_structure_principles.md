## Principles Extracted

### 1. **Hero Sections Are Anchors**
- Full-height or min-h-screen
- Dark gradient background (from-rc-accent to-rc-text)
- Tagline (small, uppercase, tracking-wider) → signals page purpose
- Main heading (serif, bold, large) → confident statement
- Subheading (light, conversational) → explains what it means
- **Pattern**: Tagline sets context → Heading makes claim → Subheading makes it personal

### 2. **Section Spacing Creates Rhythm**
- Major sections: py-24 md:py-32 (consistent breathing room)
- Alternating backgrounds: accent/text → warm-gray → bg (creates visual pause)
- Border-top on each section (subtle visual break)
- Between related ideas: pt-2 or pt-3 (breathing room within section)

### 3. **Typography Hierarchy Is Minimal But Clear**
- h2/h3: serif, bold, uppercase tracking-wider (section titles)
- Body: sans-serif, light, clear hierarchy through spacing (not font size)
- Emphasis: font-medium or font-semibold (anchor statements only, rare)
- No mixing of styles within a section

### 4. **Left-Alignment Creates Conversational Tone**
- Not centered (centers feel formal/ceremonial)
- Not right-aligned
- Left-aligned throughout (matches landing page, creates continuity)
- Text flows naturally, like someone speaking to you

### 5. **Content Structure: State > Explain > Show**
- State the claim/truth (short, bold)
- Explain the context (medium, light)
- Show the evidence (stories, numbers, examples)
- **Never** start with explanation or evidence

### 6. **Visual Elements Serve Purpose, Not Decoration**
- Partner grids (2/5/7 columns) — shows three tiers visually
- Story cards with images — makes people real
- Metrics cards — transforms numbers into context
- No decoration for decoration's sake

### 7. **Motion/Animation Is Subtle**
- Scroll-reveal animations (fade in on viewport)
- Hover states on interactive elements (partner cards, links)
- No distracting or fast animations
- Framer Motion with easing [0.25, 0.46, 0.45, 0.94]

### 8. **Consistency Across Pages**
- Same hero pattern (tagline → heading → subheading)
- Same spacing rhythm
- Same color alternation
- Same typography hierarchy
- Creates sense of unified platform, not separate pages
