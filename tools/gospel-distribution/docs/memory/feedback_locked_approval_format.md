# LOCKED APPROVAL EMAIL FORMAT (NON-NEGOTIABLE)

**The Rule:** All approval emails MUST follow the locked format documented in /teach skill. NO CUSTOM FORMATS. NO EXCEPTIONS.

**The Format (from /teach skill lines 163-194, UPDATED Oct 4, 2026):**

```
RAW QUOTE SET RECEIVED:
"[Exact raw quote as received from email]"

---

**[TITLE]**

**VERSION A: Extract HIDE reel from locked /preach**

Full /preach (current):
"[Full /preach piece]"

**Scripture:** [Chapter:Verse] — "[Full verse text]"

Extracted 40-sec HIDE reel:
"[40-second HIDE reel extracted]"

---

**VERSION B: Build 40-sec HIDE reel from scratch**

"[40-second HIDE reel built from scratch]"

---

**VERSION C: The Posted Letter (NO TEMPLATE MARKERS — COMPLETED LETTER FORMAT)**

[Title — Assumption challenger]

[Locked /preach exactly, no additions]

[Punchy realization — close]

---
```

**CRITICAL FORMATTING RULE FOR VERSION C:**
- NO "**Title:**" label
- NO "**Body:**" label  
- NO "**Close:**" label
- Just the completed letter, ready to post
- Natural spacing, flows like a real letter
- Approval email shows VERSION C exactly as it will appear on website/Substack

**Example:**

```
You're Not Trapped

Unforgiveness due to offence is one of the traps satan, the enemy of our souls, uses to hold us in bondage.

When we get offended, we hardly realise that we are trapped.

Offence itself is not deadly but harbouring or keeping it in our heart makes it deadly.

Offence has created a wall between us and God.

You will receive in a moment what you have been seeking for years, the moment you let go of your offence.

Let it go.
```

NOT:

```
**Title:** You're Not Trapped
**Body:** [text]
**Close:** Let it go.
```

**Note added Oct 4, 2026:** 
- Raw quote set MUST appear at the top of every approval email
- VERSION C must be void of all template markers
- VERSION C approval shows final, completed letter format as it will post
