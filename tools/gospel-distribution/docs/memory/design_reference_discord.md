# Discord Design System — Complete Reference

## Core Philosophy

**Game world behind a chat bubble** — every section is a self-contained environment with its own lighting and cast of characters.

The page is an **environment you enter**, not a broadcast you consume. Deep cosmic blue fills every section like a starfield—it's a total atmosphere, not just a background choice.

## Key Design Principles

1. **Extreme Color Restraint** — Blurple (#5865F2) appears ONLY on primary CTAs. Everything else is dark neutrals (blacks, charcoals, whites, Fog #BABCD9). The single saturated color creates instant recognition as the only chromatic anchor.

2. **Typography as Authority** — ABC Ginto Nord 800, all-caps, tight -0.01em tracking slams headlines into dense rectangular blocks that feel "stamped metal." No gradients, no effects—pure weight and mass create authority.

3. **Self-Contained Sections** — Each section is its own stage with different background (gradient card colors: purple-to-magenta, deep green). Sections don't flow into each other; they're distinct environments.

4. **Product Integration** — Shows the actual Discord UI inside 3D device frames. The mockup isn't a diagram; it's part of the illustration world. Composited into the page as if you're looking through a window.

5. **Overlap Creates Depth** — 3D characters and elements positioned at section boundaries, overlapping cards. No drop shadows—depth comes from artistic overlap, not CSS elevation.

6. **No Soft Defaults** — No drop shadows on cards, no gradient text, no rounded corners below 12px. Every decision is stated clearly.

## Color System

**Page Background:** #0E0F2D (deep indigo)  
**Primary Accent:** #5865F2 Blurple (CTA buttons ONLY)  
**Text on Dark:** #FFFFFF (headlines), #BABCD9 Fog (body)  
**UI Neutrals:** #23272A (not-quite-black), #2C2F33 (dark-charcoal)

**Extended Palette** (for in-product UI or illustration):  
Spring Green #57F287, Fuchsia #EB459, Vivid Cerulean #00B0F4, Ember Orange #FDA220

**Critical Rule:** Blurple is the ONLY saturated color in the layout chrome. No gradients, no background fills with Blurple. It exists only on primary CTAs.

## Typography

**Headline Font:** ABC Ginto Nord 800, all-caps, -0.01em tracking (creates -0.56px at 56px)  
**Body Font:** ABC Ginto 400/500, 16px/1.5, +0.013em letter-spacing  
**Product UI Font:** GG Sans 400, 16px/1.5 (for mockups)

**Type Scale:** 16px body → 36px heading-sm → 48px heading → 56px heading-lg → 61px display  
All with very tight line-heights (0.86–1.2) because all-caps tracking is so condensed.

## Layout & Spacing

**Base unit:** 4px  
**Section gap:** 80–120px (generous breathing room)  
**Card padding:** 32–48px  
**Element gap:** 8–16px  
**Page max-width:** 1200px  
**Border radius:** Cards 16px, buttons 12px, feature panels 24px, pills 104px

## Critical Don'ts

- Never use white/light page background
- Never mix-case the headlines (all-caps is the style)
- Never place Blurple as background on large areas
- Never add drop shadows to cards
- Never use gradient text on headlines
- Never reduce button radius below 12px
- Never use Greyple or Dim Grey as primary text colors

## Imagery

Entirely 3D-rendered illustrations + product screenshots. No photography. Characters have soft subsurface lighting, purple-blue-tinted shadows, saturated clothing. Posed dynamically, placed off-axis. Product screenshots composited into device frames (phone outline, monitor bezel) in matching 3D style—the product feels like part of the world, not a flat screenshot.

## Similar Brands Using This Approach

Roblox, Twitch, Epic Games Store, Spotify (gaming campaigns), Supercell

## How This Applies to Brother Jimi

**Principles to steal:**
- One controlled accent color (not Blurple, but a Gospel color—gold or deep red)
- Typography that declares (bold, clear, no hedging)
- Self-contained sections showing what happens (not why)
- Product mockup integration (Telegram voice chat, real prayer)
- Extreme restraint (minimal colors, minimal copy)
- No soft UI tricks—clarity through contrast

**Principles to adapt:**
- Environment feel: Instead of dark cosmic, create a light, clear gathering space
- Color palette: Instead of Blurple on dark, use warm Gospel accent on neutral
- Imagery: Instead of 3D characters, show real moments from the Telegram experience
- Typography: Instead of all-caps heavy, use bold declaration type (respects the apostolic voice)

**Keep the philosophy:** Make the page feel like entering a gathering, not reading a pitch.
