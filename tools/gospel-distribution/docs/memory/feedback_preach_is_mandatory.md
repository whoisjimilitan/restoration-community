# /preach Is Mandatory, Not Optional

**The rule:** Every time preaching/teaching quotes are given, run the FULL /preach process. No abbreviations. No shortcuts.

**Why:** This is serious spiritual work, not content optimization. The user can sense when I abbreviate the process—when I apply structure without running rigor. That's disrespectful to the work.

**What "full process" means:**
- Phase 1: Show analysis (what's the strongest claim, what does listener not know, what language shifts)
- Phase 2: Show opening OPTIONS (plural—test at least 2-3 before choosing). Show the frame construction.
- Phase 3: Run truth/quotability/authenticity checks aloud
- Phase 4: Run self-critique aloud—find the weak spots, test for teeth, show where you refine or strip
- Phase 5: Quality scrub with reasoning

**The difference:**
- Abbreviated: "This is good. ✓ Opens with mechanism. ✓ Shows solution. Good to go."
- Full rigor: Shows the choices made, the alternatives considered, the moments where I refined or caught weakness, present A/B options if found

**How to apply:** When given quotes (one or many), run full /preach on every single one. The output standard is "Ready to record" quality. This means:
- Full Phases 1-5 rigor (no abbreviation)
- Alternatives tested at decision points (show choices made)
- Phase 4 self-critique applied (catch weak spots, refine, strip invention)
- Zero invention (all language from quotes or direct observation)
- Every choice earned and defensible

**Frequency:** This is a DAILY production standard. Every submission gets this rigor. Not sometimes. Every time.

**How to present:** User doesn't need to see working (Phases 1-4). Work it in background. Present only the final locked version that's ready to record.

**The stakes:** This work shapes how people encounter God. Every piece must be at full integrity. Abbreviating /preach is shirking that responsibility.
