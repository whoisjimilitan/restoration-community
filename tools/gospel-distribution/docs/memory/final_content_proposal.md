## PSYCHOLOGICAL FLOW (Why This Works)

**Testimonies**: Recognition → Witness → Permission → Action
- User sees themselves in stories
- Realizes transformation is real and possible
- Feels invited (not pushed) to take next step

**Impact**: Problem → Solution → Cost Reality → Invitation
- Numbers show real transformation
- Theology explains why it works
- Partnership invitation feels natural

**Partnership**: Philosophy → Three Types → Thank You → Call
- Opens with mindset (problem vs. calling)
- Shows existing partners (credibility)
- Emphasizes necessity (thank you, not begging)
- Invites self-identification
