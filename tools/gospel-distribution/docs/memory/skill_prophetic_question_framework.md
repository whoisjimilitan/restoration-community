# /loom — Prophetic Question Framework

## THE PROCESS

For each quote:

1. **Identify the principle** — What is really being revealed at the spiritual level?
2. **Craft an opening** — Not always a question. Choose the type that SERVES this truth:
   - Direct question: "What is your real battle?"
   - Rhetorical question: "What if the enemy you're fighting isn't the one trying to trip you?"
   - Metaphor: "You're running your race, but there's an invisible force designed to make you stumble."
   - Analogy: "You've been trained to fight what you can see. Your real enemy operates where you can't."
   - Story/scenario: "You're exhausted from running hard, but you're running against an opponent you've never named."
   - Common fact: "Most believers lose their race not because they're weak, but because they're fighting the wrong enemy."
   - Combination: Blend any of the above
3. **Verify direct answer** — Can the quote clearly answer the opening? If not, revise the opening.
4. **Let the quote answer** — The quote's first line answers immediately
5. **Check internal coherence** — Are there logical gaps that will confuse the listener? If yes, add a bridging line.
6. **Find Scripture** — One verse that confirms the principle
7. **Refine for quality** — Study and tighten:
   - Remove redundancy (no two verbs doing the same job)
   - Use authoritative connectors ("Know this" vs "But first, realise")
   - Add specificity to the outcome (what's gained, what's defeated, what's your weapon)
   - Tie language back to core themes (repetition of key words/concepts)
   - Add one concrete statement the listener can grip ("That is your weapon")
8. **Run full critique test** — Look for lightbulbs, refinements, better ifs
9. **No CTA** — Let it end with Scripture. The revelation is the call.

## THE GUARDRAILS

✓ **Sounds like how you'd actually say it** — Simple, direct, human. No elevation.

✓ **Every word earns its place** — No decoration, no filler.

✓ **Challenges an assumption** — Shifts perspective, doesn't confirm.

✓ **Passes Graham's four-part** — Correct, precise, novel, useful.

✓ **Doesn't sound systematic** — Sounds lived, earned, human. Not interchangeable.

✓ **Quote's first line answers immediately** — The structure that works.

✓ **No explanation around it** — Interrogative only. Confronting. Lean.

✓ **Emerges from principle, not problem** — Deep understanding of what's true, not surface symptoms.

✓ **Irreplaceable** — Distinctly your voice. Could only come from you.

✓ **Speaks plainly, not wisely** — Truth stated directly. No performing.

✓ **Vary the interrogative form** — What/Why/When/How/Are based on what the principle requires.

✓ **Only add a connector if clarity requires it** — Not because it's the pattern.

✓ **The connector must emerge from what's already there** — Not invented, not inferred beyond what's said.

✓ **Question-Answer Direct Match** — Before presenting, verify the quote clearly answers the question. Point to the line. If not, revise the question to match what the quote actually addresses.

✓ **Quality check at end** — Critique question and verse for lightbulbs/better ifs. Present alternatives as A/B if found. Mark "Good to go" if not.

✓ **Refine for mastery** — Before final presentation:
  - Are there redundant verbs or concepts? Remove.
  - Are connectors authoritative? Change "but first" to "know this."
  - Does the close specify outcome? Add concrete graspables ("that is your weapon").
  - Do key words repeat to reinforce theme? Weave them through.
  - Does the listener have one thing they can actually grip? Ensure yes.
  - **Motif closure:** If a key word appears in opener (e.g., "prize"), does it loop back COMPLETELY in the close? Partial reference isn't enough. Complete the circle.

✓ **No CTA** — End with Scripture. Let the revelation call internally.

## ADVANCED PRINCIPLES — Learned Through Refinement

**Parallel Affirmation > Subordination**
- Weak: "You're running toward a prize, but there's an obstacle"
- Strong: "It is true you're running toward a prize, but it is also true there's an obstacle"
- Both truths stand equally heavy. Neither negates the other. Creates balance and weight.

**Pronoun Variation Creates Intimacy**
- Singular "you" = confronts individually
- Communal "our/us" = includes listener in community
- Variation (you → our → us) shows "you are not alone; we face this together"
- Watch for consistency within sections; intentional shifts work better than accidental ones

**Weakness → Weapon Chain**
- Identify the SPECIFIC weakness ("your capacity to believe and speak God's Word")
- Show how the solution DIRECTLY ATTACKS that weakness (speaking God's Word)
- Listener now sees: "I'm not just doing an action; I'm assaulting my own obstacle"
- This makes application 10x more powerful because it's not abstract instruction; it's battlefield clarity

**Message Architecture Flow**
1. Opener (establish two truths / stakes)
2. Problem (wrong approach)
3. Real problem (spiritual reality)
4. Specific weakness (the actual battlefield)
5. Example (proof it's possible)
6. Solution (the answer named)
7. Method (HOW it works)
8. Application (what YOU do)
9. Outcome (what happens when you do it)

If any step is vague, the next step won't land. Test each connection.

## ITERATIVE REFINEMENT — The Locked Version Process

**This is how each message reaches final quality:**

### Phase 1: Build the Draft
Follow the main process above. Get to a working version.

### Phase 2: Critique and Micro-Adjust
Run this checklist:

✓ **Identity grounding** — Does the opener ground this in the listener's identity? ("As a Christian..." / "If you believe..." / "When you face...") Make it specific to WHO should hear this.

✓ **Specific weakness naming** — Is THE weakness identified clearly enough that the application directly attacks it? (Not vague weakness, but THE weakness the solution addresses)

✓ **Outcome specificity** — Is the actual outcome/goal named? (Not "prize" but "eternity with God" / "freedom from fear" / "power to stand") Complete the loop.

✓ **Micro-adjustment decision** — For each change:
  - Does it serve flow, coherence, or revelation?
  - Does it make the message land STRONGER for the listener?
  - Does it GAIN clarity, memorability, or truthfulness?
  - If YES to any → make the change
  - If NO → preserve original
  - Rule: Tweak when it serves the message. Preserve when it's already strong. The message landing matters more than keeping original wording.

✓ **Pronoun consistency** — Are pronouns intentional (singular "you" vs communal "our/us") or accidental? Fix if accidental.

✓ **Motif completion** — Do opening images/words loop back in the close? (Prize mentioned at start → named in close)

### Phase 3: Lock and Go
Before final presentation, verify:

✓ Each sentence earns its place (no filler)
✓ Every line connects logically to the next (no gaps)
✓ Specific weakness is identified
✓ Solution directly attacks that weakness
✓ Outcome is named
✓ Opening image completes in close
✓ Scripture verse confirms the principle
✓ No two messages look the same (emerges from principle, not template)
✓ All premises are Scripturally grounded
✓ Reasoning is factually sound

**Message is locked when all checkboxes pass.**

## VARIATION PRINCIPLE — No Template Look

Each message must feel DISTINCT, not like it came from a formula:

- Opener type varies (question, metaphor, story, declaration, parallel affirmation)
- Length varies based on principle, not fixed structure
- Pronoun usage is intentional to the message's emotional arc
- Weakness identification is unique to each truth
- Application is specific to the principle, not generic "do this"
- Close echoes the specific opening, not a templated close

**Test:** If a listener heard two messages, would they feel like they came from the same formula, or from two different meditations on Scripture?

If template-y → rework until it emerges from the principle, not the process.

## HOW TO USE THIS FRAMEWORK FOR NEW QUOTES

When given a new quote:

1. Read it completely
2. Ask: What principle does this reveal?
3. Ask: What assumption does this challenge?
4. **Choose the opener type** that SERVES this truth best — not just question. Consider metaphor, analogy, story, common fact, rhetorical question, or combination.
5. Craft the opening (4-8 words, natural language, authority matching the voice)
6. **TEST: Point to the line in the quote that answers the opening. Can you find it clearly?**
   - If YES → proceed
   - If NO → revise the opening to match what the quote actually addresses
7. **Check internal coherence** — Are there logical gaps? Add bridging lines if needed.
8. Verify the quote's first line answers it
9. Find one supporting Scripture
10. **Check for logical gaps** — Before refinement, verify coherence:
    - Does the listener understand the parallel? (If using an example like Jesus, bridge it to their reality: "You face the same...")
    - Is personal application clear? (If mentioning weakness/tendency, add "your specific" to make it personal, not general)
    - Does the instruction follow from the teaching? (If saying "speak," ensure listener knows WHAT to speak, based on earlier context)
    - Can listener follow the reasoning without gaps? (Trace the flow: Problem → Why → Solution → Method → Application)
    - **Identify the specific weakness** — Not vague weakness, but the EXACT weakness you're addressing. This makes the solution land with power because the application directly attacks the identified weakness.

11. **Refine for mastery:**
    - Remove redundancy
    - Tighten connectors (authoritative, not instructional)
    - Add specificity to outcome (what's gained, what's your weapon)
    - Repeat core words/themes
    - Ensure one concrete statement listener can grip
    - **Motif closure:** Key words from opener must loop back COMPLETELY in close
11. **Choose the title** — Match the message's energy and PURPOSE:
    - If the close is action-oriented ("that's how you..."), title should signal METHOD ("How to...")
    - If the close emphasizes destination/stakes, title should signal those
    - Title should mirror the message's ENERGY (poetic vs practical)
    - Title should prepare the listener for what's coming
12. Run full critique test — look for lightbulbs/better ifs
13. If found: Present A (original) and B (alternative) — user chooses
14. If nothing: Mark ✓ Good to go
15. Format: Title → Opening → Quote → Scripture → Critique → Done

**Do not invent reasoning, narrative, or explanation. Do not add CTA. Let the structure speak. Truth calls internally. Every word earns its place. Refinement is relentless. Title and message must be energetically aligned.**
