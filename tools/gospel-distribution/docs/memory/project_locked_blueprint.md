## APPROVAL WORKFLOW (Email-Based)

### Daily Flow
1. **Boba sends quotes** (7pm GMT+1)
2. **Pipeline detects** (within 5 min of check)
3. **Extract & process:**
   - /preach on each quote (all 5 phases, evidence logged)
   - /teach on each (VERSION A + VERSION B, evidence logged)
4. **Send approval email** to whoisjimi.today@gmail.com
   - Contains: All /preach outputs + VERSION A + VERSION B + evidence
   - Subject: "Daily reflections ready for review — [DATE]"
5. **You review** (2-3 minutes optional)
6. **You reply:** 
   - "Approve" = all 3 publish
   - "Redo #2" = piece 2 revised, 1 & 3 publish
7. **Gmail API detects reply** → triggers publishing
8. **Publishing happens automatically:**
   - Website: Live at brotherjimi.com
   - Substack: Posted to free tier
   - Social: Queued via Buffer
   - Email: Digest sent to subscribers
   - Evidence: All URLs logged
