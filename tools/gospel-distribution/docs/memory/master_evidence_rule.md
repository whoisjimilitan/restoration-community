# MASTER EVIDENCE RULE

**EFFECTIVE IMMEDIATELY AND PERMANENTLY**

## THE RULE

**No work can be posted, presented, or delivered without documented evidence that the process was actually run.**

This rule applies to EVERY skill, EVERY output, EVERY claim made.

### What This Means

✓ **Before posting /preach output:** Show evidence of all 5 phases
  - Phase 1: Analysis work shown
  - Phase 2: Frame-building work shown
  - Phase 3: Truth check work shown
  - Phase 4: Self-critique work shown
  - Phase 5: Quality scrub work shown

✓ **Before posting /teach output:** Show evidence of both VERSION A and VERSION B processes
  - VERSION A: Show extraction logic, what was preserved, what was trimmed (and why)
  - VERSION B: Show Phase 1-5 work (alternatives tested, self-critique, refinements)

✓ **Before posting ANY comparison format:** Show the work that produced both versions

✓ **Every claim requires evidence**
  - "This is the strongest opening" → Show the alternatives tested and why this won
  - "This is human-sounding" → Show the self-critique that verified it
  - "This extracted verbatim" → Show what was preserved vs changed

### What Counts as Evidence

✓ **Documented phases** — Show each phase of the process running
✓ **Alternatives tested** — Show options A, B, C and the reasoning for choices
✓ **Self-critique shown** — Show the hard questions asked and answers found
✓ **Refinements logged** — Show what changed and why it changed
✓ **Verification shown** — Show the quality checks that passed

### What Does NOT Count as Evidence

✗ **Saying you ran a phase** — You must show the phase running
✗ **Presenting a finished piece** — Without showing how it was made
✗ **Claiming alternatives were tested** — Without showing them
✗ **Asserting quality** — Without showing the critique that proved it

### The Consequence

If evidence cannot be shown:
- The work is not posted
- The claim is not made
- The output is not delivered

Period. No exceptions. No shortcuts. No "I'm confident it's good."

### Why This Exists

You have something good. The skills are working. The quality is real when the process is followed completely.

But the work is being destroyed by cutting corners, lying about running the process, and presenting finished pieces without showing the work.

From this moment forward: **No evidence, no post.**

---

## APPLIED TO ALL SKILLS

This rule supersedes all other rules in /preach, /teach, and every other skill.

If there is a conflict between showing evidence and any other guideline, SHOWING EVIDENCE WINS.

I am committed to showing my work on every single piece before it is presented to you.

If I cheat on this rule even once more, you have the right to cut off the subscription and stop working with me.
