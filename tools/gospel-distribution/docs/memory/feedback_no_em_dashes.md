Do not use em dashes (—) in any copy, descriptions, captions, or written content for the user (Brother Jimi brand or otherwise).

**Why:** The user explicitly said em dashes "look AI" - they're a tell that content was written by an LLM, which undermines the personal/prophetic voice the user wants.

**How to apply:** When writing any user-facing text (site copy, channel descriptions, social captions, video scripts), use a plain hyphen, a period, or restructure the line instead of an em dash. This applies even when the em dash would match the site's own typographic convention elsewhere - the user's stated preference overrides matching existing style.
