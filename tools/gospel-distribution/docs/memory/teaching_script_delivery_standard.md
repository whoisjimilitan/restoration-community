## The Delivery Standard

Every teaching script must meet these criteria:

✓ **One idea per line** — No three clauses strung together. No complex subordinate structures. One thought per line.

✓ **Clear progression** — Each stage should show this pattern:
  - What it isn't (the correction)
  - What it is (the definition)
  - What it requires (the demand)
  - What it produces (the outcome)

✓ **Sets up the next stage** — Each stage must logically prepare for the next. Stage 2 sets up Stage 4, Stage 5 sets up Stage 6, etc.

✓ **Easier to remember** — Each line lands independently. The audience can follow without effort. No line requires rereading.

✓ **Easier to deliver** — No breath problems. No confusion. Natural pause points. Conversational rhythm. Oral delivery is smooth.

## How to Apply

**When writing Stage 2:** Ask "Does each line stand alone? Can the speaker deliver this without stumbling?"

**When writing Stage 4:** Ask "Is there one idea per line, or am I cramming multiple thoughts together?"

**When reviewing any stage:** Count the ideas. If one line has 2+ ideas, split it.

**Test for delivery:** Read it aloud. If you gasp for breath, the line is too long. If the audience would get lost, the idea is too complex.

## Example

**Before (complex):**
"You can know about God, agree with His opinion and still refuse to believe in Him."
→ Three ideas: know about God, agree, refuse to believe

**After (one idea per line):**
"You can know God is real and still refuse to believe in Him."
→ One clear idea: knowledge ≠ belief
