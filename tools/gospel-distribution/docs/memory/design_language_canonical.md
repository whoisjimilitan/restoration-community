# Design Language is Canonical

The file `/Users/jimilitan/Projects/restoration-community/apps/web/DESIGN_LANGUAGE.md` is the single source of truth for all page design and polish.

**Never build a public page without reading and following DESIGN_LANGUAGE.md first.**

## Core Standards (Quick Reference)

**Spacing:** All sections use `py-24 md:py-32` (generous breathing room). Never reduce to py-20 or py-28.

**Background Pattern:** Alternate white (bg-rc-bg) and gray (bg-rc-warm-gray):
- Section 1: white
- Section 2: gray
- Section 3: white
- Section 4: gray
... continue pattern

**Dividers:** Every section (except first) has `border-t border-rc-border`

**Content Width:** Wrap in `max-w-2xl mx-auto` (copy) or `max-w-5xl mx-auto` (grids)

**Why:** Creates premium, beautifully-typeset book feeling. Breathing room + rhythm = intentional design.

**When to deviate:** Only for hero sections, modals, or admin dashboards. All public ministry pages (homepage, testimonies, partnership, etc.) use this language exactly.
