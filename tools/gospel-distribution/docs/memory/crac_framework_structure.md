## CRAC Framework for Teaching Scripts

**CRAC ensures every teaching makes ONE argument, not many.**

### The Four Parts

**C - CONCLUSION (Opening)**
State the problem or question the audience recognizes in themselves.
- Short, direct, relatable
- Creates tension that the teaching will resolve

**R - RULE (Definition/Foundation)**
Establish ONE single rule or principle that governs the answer.
- This is the foundational truth
- Scripture supports this rule
- Everything that follows applies this one rule

**A - APPLICATION (Evidence & Proof)**
Show how the rule applies to the specific situation.
- Multiple angles of application
- Illustrations that prove the rule
- Address objections
- Build momentum toward the conclusion

**C - CONCLUSION (Call to Action)**
Restate the problem with the solution now clear.
- What they must do
- Why it will work (because of the rule)
- Send them out with power

---

## How This Maps to Our Teaching Structure

| CRAC Part | Teaching Stages | Purpose |
|-----------|-----------------|---------|
| **C** | Stage 1 | Question that creates tension |
| **R** | Stage 2 | The singular rule/definition |
| **A** | Stages 3-6 | Application: they're not doing it, but they can, proof it works |
| **C** | Stage 7 | Do this now. Here's why. Go. |

---

## The Critical Rule

**Only ONE rule per teaching.**

Not:
- "Selective belief is bad" AND "Doing is believing"

But:
- "DOING IS BELIEVING" (with selective belief as just one example of not doing)

---

## When to Use CRAC

**Before finalizing ANY teaching script:**
1. Identify the ONE singular argument
2. Verify every stage serves that argument
3. Remove any secondary arguments (they dilute the message)
4. Ensure CRAC structure is clear

If you can't identify the single rule, the teaching is not ready.

---

## Quality Checklist (All Three Standards)

Every teaching script must pass:

✓ **VALIDITY & PREMISE** — Is it logically sound and scripturally true?
✓ **DELIVERY STANDARD** — One idea per line, clear progression, memorable?
✓ **CRAC STRUCTURE** — Does it make ONE coherent argument?

A teaching that passes all three cannot be challenged from any direction.
