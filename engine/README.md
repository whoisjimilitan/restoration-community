# Counsel engine (snapshot, 22 November 2026)
The scripts that made the 22 to 30 November letters and cards. Not deployed.
- letters/week1.py, vic.py: the letters (Jimi's sentences; {{...}} marks words added).
- letters/build.py: builds /counsel/<slug>/index.html pages. letters/desc.json: search descriptions.
- cards/card.py: makes the -post, -status and -og type cards (DUST=1).
- letters/COUNSEL-STANDARD.md: the locked rules.
Paths inside are from the build machine; they are made portable when the monthly run is set up in late November.
