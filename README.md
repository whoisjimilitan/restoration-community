# Restoration Community

The canonical home of the Restoration Community project.

This repository contains the governance documents, requirements, architecture, and implementation for the Restoration Community platform.

## Quick Start

See [REPOSITORY_GUIDE.md](REPOSITORY_GUIDE.md) to understand the repository structure and how to contribute.

## Structure

- `governance/` — Authoritative governing documents
- `architecture/` — Working design artifacts
- `decisions/` — Architecture decision records
- `docs/` — Working documentation and notes
- `implementation/` — Application source code
- `infrastructure/` — Deployment and infrastructure
- `tests/` — Automated tests
- `templates/` — Reusable document templates
- `assets/` — Branding and visual resources

## Stewardship

This repository is stewarded by the Restoration Community team.
