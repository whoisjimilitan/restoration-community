- **White:** #FFFFFF
- **Gray:** #F5F5F5 (warm gray for sections)

- **Text Muted:** #888888 (60% opacity)

### **Typography:**
- **Headlines:** Serif (font-rc-serif), bold, large
- **Body:** Sans-serif (Tailwind default), light weight, 16-18px
- **Logo Captions:** Small (12-14px), muted gray

### **Spacing:**
- **Section padding:** py-24 md:py-32 (vertical breathing)
- **Card gaps:** 24px (horizontal), 32px (vertical)
- **Logo size progression:**
  - Founding: 180px × 140px
  - Standing: 140px × 110px
  - Prayer: 100px × 80px
  - *Visual hierarchy through size*

### **Interaction:**
- **Logo hover:** Subtle shadow, slight scale (1.05x)
- **Logo link:** Opens in new tab (to partner's site)
- **Button hover:** White bg → slight color change, shadow

## CRITIQUE & REFINEMENT

### **Current State Issues:**
1. **Logo mockups are too TEXT-HEAVY** — Real organizations have visual marks
2. **Spacing feels generous but could be TIGHTER** — Not every section needs maximum padding
3. **Tier transitions are CLEAR but need VISUAL BREATHING** — Sections blend into each other
4. **CTA section feels ISOLATED** — Should feel like natural next step
5. **Prayer Partners section might be TOO MANY logos** — Doesn't convey exclusivity of tiers

### **Refinements:**

**Fix 1: Logo Design (Make Them Look Real & Premium)**
- Founding logos: Professional icon + text (no cheesy design)
- Standing logos: Icon-based (simpler than founding)
- Prayer logos: Icon only (ultra-simple, elegant)
- All logos: Consistent visual language (not random styles)

Example improvement:
```
BEFORE (too text-heavy):
┌──────────────────────┐
│ Grace Foundation     │
│ International        │
│ (Lorem ipsum text)   │
└──────────────────────┘

AFTER (icon-driven, premium):
┌──────────────────────┐
│  [Simple icon: G]    │
│   Grace Foundation   │
│  (no description)    │
└──────────────────────┘
```

**Fix 2: Section Breathing (Reduce Visual Clutter)**
- Founding section: Larger padding, fewer logos shown (3-4 max)
- Standing section: Medium padding, 4-5 logos
- Prayer section: Smaller padding, more logos (shows growth)
- Each tier VISUALLY DISTINCT through spacing, not just size

**Fix 3: CTA Integration (Not Isolated)**
- Remove the "Your Partnership Starts Here" section entirely
- Instead: Simple footer line before footer
  ```
  Standing with us? Reach out.
  [Start a Conversation]
  ```
- Feels like natural next step, not hard sell

**Fix 4: Logo Consistency (Professional Appearance)**
- All logos use 2-color palette (teal accent + dark/gray)
- All logos in same visual style (no random gradients/effects)
- Logos scale smoothly (180 → 140 → 100)
- Caption text consistent (14px, muted, centered)

**Fix 5: Tier Clarity (Visual Hierarchy)**
- Add subtle divider between tiers (thin line or larger spacing)
- Tier label ABOVE logos (not as caption)
- Tier label color: Muted but intentional
  - Founding: Darker teal
  - Standing: Medium gray
  - Prayer: Light gray
